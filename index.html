🤖 IA — Claude (Gratis)
El asistente de Apuntes usa Claude de Anthropic de forma 100% gratuita. No necesitas ninguna API Key.
✅ En Claude.ai — Gratis sin config
Cuando usas StudyCore dentro de Claude.ai, la IA funciona gratis y sin clave. Abre Apuntes IA y empieza 🚀
📱 En PWA / App instalada
Si instalas StudyCore como app (PWA) en tu móvil o PC, necesitas una API Key de Anthropic gratuita para que la IA funcione.

Cómo conseguirla (gratis):
1. Ve a console.anthropic.com y crea una cuenta
2. En el menú lateral entra a API Keys
3. Pulsa Create Key, ponle un nombre (ej. "StudyCore")
4. Copia la clave (empieza por sk-ant-...)
5. Pégala abajo y pulsa Guardar
⚡ Anthropic da crédito gratuito al registrarse. Con uso moderado dura semanas.
